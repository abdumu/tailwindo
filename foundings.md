# Foundings (Mission 2 & General)

- **F-2026-03-14-001**: Autodetection fails on very short Playwright component snippets unless explicitly provided using the `--from` flag (now fixed in the harness).
- **F-2026-03-14-002**: Many geometric discrepancies in intrinsic margins, paddings, and font sizes across Bootstrap, Bulma, and Foundation elements cannot rely merely on relative Tailwind scale mapping (like `p-4`) without causing 2-5px errors. This enforces heavy usage of arbitrary variables `[calc()]` to exactly mimic base mappings, or moving complex sibling selection into `--components`.
- **F-2026-03-14-003**: Empty shadow layers (`rgba(0,0,0,0)`) returned by computed CSS styles need to be stripped to successfully compare element effects with Tailwind equivalents in Playwright.
- **F-2026-03-14-004**: Arbitrary bracket values (like `tw:p-[1rem]`) fail during Tailwind v4 compilation when used inside `@apply` pseudo-classes. They must be explicitly unboxed into native CSS declarations (like `padding: 1rem`) during the `--components` generator phase.
- **F-2026-03-14-005**: Tailwind v4's new CSS-first `@apply` engine cannot process arbitrary property values (e.g. `@apply py-[0.5rem]`). To achieve exact pixel-perfect geometric parity with framework elements (like `.btn-lg`), the converter must directly emit literal utility classes instead of relying on generic `@apply` components.
- **F-2026-03-14-006**: Bootstrap and Foundation use specific exact breakpoints (e.g., `1140px`) for their containers. Mapping `.container` to `tw:container` results in `1280px` or `1536px` due to default Tailwind theme configurations. This causes a ~100px discrepancy in the `width` property. This difference is idiomatic and has been quarantined. To fix, either implement a fidelity-first mapping with arbitrary `max-w-[1140px]` tokens or strictly specify them in a components CSS override.
- **F-2026-03-14-007**: Modifier classes (like `btn-sm`) must explicitly filter out and replace the base dimensions (like `py-`, `px-`, `text-`) from the parent `.btn` mapping array during the extraction phase, to prevent compound-class CSS order collision.
